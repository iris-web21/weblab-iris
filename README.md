# WebLab Iris

Одностраничный сайт-портфолио для студии, которая делает дипломы и проекты по веб-разработке под ключ: сайты, базы данных, документация по ГОСТ, презентация и защита.

## Что внутри

- **Главная страница** с секциями: hero, «почему со мной», кейсы, стек, цены, гарантии, услуги, процесс, FAQ, отзывы, контакты.
- **6 страниц кейсов** с задачей, стеком, ключевым фрагментом кода и результатом.
- **Фильтрация кейсов** по типу: сайты / базы данных / веб-приложения.
- **Клиентский роутинг** на хешах (`#case-...`) без перезагрузки страницы.
- **Cookie-баннер** с сохранением выбора в `localStorage`.
- **Мобильное меню** с фокус-ловушкой и закрытием по `Esc`.
- **Адаптивная вёрстка** от 320px, поддержка `prefers-reduced-motion`.
- **Семантическая разметка** и ARIA-атрибуты для доступности.

## Стек

- HTML5 (семантика, ARIA)
- CSS3 (Grid, Flexbox, кастомные свойства, `clamp()`, `aspect-ratio`, `conic-gradient`)
- JavaScript (vanilla, без фреймворков)
- Google Fonts: Unbounded, Inter, JetBrains Mono
